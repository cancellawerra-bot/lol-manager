# 다음 개발 방향 — 화면과 감독의 선택

2026-11-19 오너 설명: 기능을 나열하고 매번 장시간 클리어율을 재는 것이 목적이 아닙니다. LCK Manager 26을 참고해 LOL Manager의 디자인과 운영 재미를 발전시키는 것이 우선입니다.

- [공식 가이드](https://pepper2.itch.io/lck-manager-26/devlog/1637941/lck-260823-updated), [로드맵](https://pepper2.itch.io/lck-manager-26/devlog/1637314/roadmap-823-updated).
- 저장소 [실플레이 구조 조사](research/STRUCTURE.md), [플레이 기록](research/play/NOTES.md), [초기 보고서](research/REPORT.md)는 이전 빌드의 직접 플레이 자료입니다. 이번 확인에서 새 빌드를 처음부터 끝까지 다시 플레이했다고 주장하지 않습니다. 연결 브라우저 사용이 제한되어 현재 설명/공식 문서와 기존 실플레이 근거를 구분했습니다.

아래는 이 자료를 바탕으로 한 우리 게임의 설계 판단입니다. 원작 코드·사진·스크린샷·화면 배치를 가져오지 않습니다.

## 첫 개발: 감독 홈과 결정 목록

표와 안내 문장을 늘리는 대신 다음 경기를 가장 크게 보여주고, 감독이 지금 판단할 것과 판단 뒤 바뀐 것을 연결합니다.

1. **감독 홈 디자인:** 다음 경기/대회 단계/현재 시즌 목표를 중심에 놓습니다. 현재 선발 5명은 포지션과 실제 챔피언 아이콘 중심으로 보여주고, 피로·훈련·출전 약속의 상태를 비교합니다. 상세 통계는 펼쳐 보게 해 홈의 밀도를 낮춥니다. 남색 바탕, 선명한 실행 버튼, 우승/성취의 따뜻한 금색, 넉넉한 간격과 글자 크기로 독자적인 화면을 만듭니다. 모바일은 다음 행동부터 세로로 정렬합니다.
2. **이번 주 중요한 결정:** 실제로 도착한 이적 제안, 만료 계약, 쉬어야 할 선수, 기한이 가까운 출전 약속, 미정 일정 등을 읽어 우선순위를 보여줍니다. 없는 사건을 억지로 매주 만들지 않습니다. 각 항목에서 기존 해당 화면/행동으로 바로 이동합니다.
3. **선택의 피드백:** 실제 저장한 피로 전후·훈련 성장·첫 선발 약속 진행·작전 목표 달성/실패를 연결해 감독이 한 선택을 이해하게 합니다. 전체 승리 원인이나 승률 보장으로 포장하지 않습니다.
4. **시즌의 감정선:** 실제 승격·프랜차이즈 진입·대회 우승·시즌 마무리에 축하/정리 화면과 새 연표 기록을 연결합니다. 실패도 다음 시즌에 남는 운영 이야기로 보여줍니다.

첫 개편은 현재 게임 상태를 보기 좋게 읽고 기존 행동을 연결하는 범위로 진행할 수 있습니다. 이후 스폰서 조건·구단주 목표·육성 투자 등 새 선택을 추가할 때는 돈/시간/기용의 실제 교환 조건을 설계합니다. 기존 선발 약속·전술·훈련·이적을 먼저 한 흐름으로 연결하고 중복 팝업을 늘리지 않습니다.

## 지킬 기준

- 2018 신생 2부 구단→2027 월즈의 프랜차이즈가 중심입니다. 별도 히스토리 모드는 취소 유지입니다.
- 선수당 한 명, 확인된 실제 기록/생년, 결측·표본 표시, 가상 금액, 챔피언 아이콘만 사용합니다. 실제 선수의 성격·발언·잠재력을 만들지 않습니다.
- 읽기/표시 변경은 해당 기능·저장 회귀·PC1280/휴대폰390·콘솔0을 확인해 배포합니다. 경기 판정·경제·난이도에 영향을 주는 변경은 기존 공식 40시드씩 전체 측정합니다.
- 다음 개발의 판단 기준은 기능 수가 아니라 화면의 이해도, 중요한 선택의 분명함, 실제 결과 피드백, 다음 시즌을 해보고 싶은 동기입니다.
