# 감독 홈 디자인 · v2.12.0

[원작 공식 소개](https://pepper2.itch.io/lck-manager-26), 저장소 [실플레이 구조 조사](research/STRUCTURE.md), [DESIGN_NEXT.md](DESIGN_NEXT.md)의 감독 중심 흐름을 참고했습니다. 원작의 코드·이미지·배치를 가져오지 않고 LOL Manager의 현재 게임 상태로 독자적인 홈을 구성합니다.

## 화면과 동선

- 큰 다음 경기 카드: 실제 상대·대회 일정·Bo 형식과 진행 버튼. 남색 경기장 선 표현, 금색 실행 버튼, 간결한 제목으로 우선순위를 만듭니다. 실제 팀 로고·선수 사진은 추가하지 않습니다.
- 지금 확인할 일: 미정 일정, 결정하지 않은 만료 계약, 현재 주간의 열린 이적 제안, 선발의 피로, 기한이 가까운 출전 약속, 재정 경고를 읽습니다. 우선 3개와 나머지 수를 표시하며 해당 기존 화면으로 이동합니다. 없는 사건은 만들지 않습니다. 피로45는 홈의 검토 표시 기준이며 경기의 피로 계수/한도 변경이 아닙니다.
- 시즌 현황과 현재 선발5명: 현재 정규 전적 또는 대회 진행 상태, 자금, 구단주 신뢰, 실제 최근 경기, 적용 카드 연도, 피로·출전 약속을 보여줍니다. 현재 구성은 실제 첫 선발의 보장이 아니며 기존 자동 로테이션과 경기 전 선택을 따릅니다.
- 선발의 챔피언은 실제 최근 출전 기록(드래프트 순서가 아닌 포지션으로 매칭), 그다음 선수 데이터의 확인된 챔피언만 사용합니다. 없으면 포지션 글자를 표시하고 챔피언 기록 없음으로 둡니다. 피로 기록이 없으면 임의의0을 기록으로 표시하지 않습니다.
- 기존 전술·시즌 자동 진행·훈련 위임은 유지합니다. 상대 상세는 펼쳐 보고, 순위/소식/일정/데이터는 아래에 정리합니다. 국제대 기간에 정규0승0패 표를 현재 순위처럼 보여주지 않습니다. 모바일은 세로 흐름, 선발은 가로 카드 대신 읽기 쉬운 행으로 보여주고 표의 긴 내용은 내부에서 스크롤합니다.
- 진행 중 경기·스토브·프랜차이즈 선택·종료를 구분합니다. 새 큰 진행 버튼은 App의 기존 onAdvance 함수를 그대로 공유하며 경기 중에는 기존 세션만 이어갑니다. 스토브/기록은 이동만 하고, 프랜차이즈는 기존 선택 영역으로 스크롤합니다.

## 선수 상세 연결 회귀 수정

시즌 카드의 선수는 2026 코어 팀 ID가 -1이라 기존 상세가 팀 색상을 읽다가 중단되는 문제를 홈 카드에서 재현했습니다. 카드/계약으로 실제 근거 시즌을 찾아 별도 상세를 보여줍니다. 당시 소속·시즌·경기수·확인된 KDA/승률/KP/GD15/DPM/CSPM과 현재 게임 종합을 구분하며 결측을0으로 채우지 않습니다. 공식 카드가 없는 게임 선수는 공식 기록 없음으로 안내합니다. 2026 코어 선수의 기존 상세도 유지합니다. 경기 선수 객체·원본 데이터·경제는 수정하지 않았습니다.

## 검증 범위

src/game·store·data/types·QA hook·public 데이터와 자산·공식 clear_rate.ts는 기준 main a980847과 동일합니다. App의 기존 진행 함수 본문도 동일합니다. 따라서 전체 밸런스 측정은 하지 않습니다.

tools/test/home-design.test.ts는 조회의 저장/난수/원자료 불변, 기록 없는 챔피언,0원 자금, 피로/계약/경기/종료 안내, 실제 경기의 포지션별 챔피언 매칭을 검사합니다. 실제 Edge PC1280/휴대폰390에서 홈/선수 상세·진행 버튼의 기존 결과 일치·중복 없는 경기 이어가기·일정 위임·약속/이적/피로 안내·스토브/프랜차이즈/종료/스위스와 긴 이름을 검사합니다. 기존 전술·출전 약속·재정/이동은 관련 회귀 검사로 확인합니다. 명시적인 피로/재정/대회 화면 검증 상황은 자연 진행/클리어 표본으로 세지 않습니다. 결과와 배포 상태는 HANDOFF 최신 변경 기록을 읽습니다.
