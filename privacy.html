개인정보 처리방침

LOL Manager · 시행일 2026-11-17

1. 수집하는 정보

사이트는 정적 교육용 웹사이트로, 회원가입·로그인 기능이 없고 Riot 계정 로그인도 요구하지 않습니다. 방문자의 이메일, Riot ID 등 개인정보를 수집하지 않습니다. 새 커리어를 시작할 때 입력하는 감독 이름은 게임 화면 표시용이며 방문자의 브라우저 안에만 저장됩니다.

2. 쿠키와 분석 도구

사이트는 쿠키, 광고, 방문 분석(애널리틱스) 도구를 사용하지 않습니다. 게임 진행 상황(세이브)은 방문자 브라우저의 로컬 저장소(localStorage)에만 저장되며 서버로 전송되지 않습니다. 브라우저 저장소를 지우면 세이브도 함께 지워지고, 방문자가 직접 내보낸 JSON 파일은 방문자의 기기에만 있습니다. 글꼴과 이미지는 모두 사이트 안에서 제공되어 외부 서비스로 요청을 보내지 않습니다.

3. Riot Games API 데이터

방문자의 브라우저에서는 Riot Games API를 호출하지 않습니다. 별도의 오프라인 수집 프로그램이 Riot Games API로 한국 서버의 공개 랭크 경기 데이터를 받아 챔피언 상성과 포지션별 시너지 통계(경기 수 포함)로 집계하며, 사이트에는 이 집계값만 표시합니다. 이 통계는 챔피언과 포지션에 관한 것이며 개별 플레이어나 방문자의 프로필이 아닙니다. 프로 선수 능력치는 공개된 LCK 공식 경기 기록(Leaguepedia 제공 경기 데이터)으로 계산하며, 선수 사진은 사용하지 않습니다. 선수 본인이 이름 사용 중단을 요청하면 즉시 익명 처리합니다.

4. 호스팅

사이트는 GitHub Pages에서 제공됩니다. GitHub는 IP 주소 등 일반적인 접속 기록을 GitHub의 개인정보 처리방침에 따라 처리할 수 있습니다. 운영자는 방문자 정보를 판매하지 않으며, 사이트를 도박이나 광고에 사용하지 않습니다.

Privacy Policy

LOL Manager · Effective 2026-11-17

1. Information we collect

The Site is a static educational website. It has no accounts or login, and it never asks visitors to sign in with a Riot account. It does not collect emails, Riot IDs, or other personal information from visitors. The manager name typed when starting a career is used only for in-game display and is stored only in the visitor's browser.

2. Cookies and analytics

The Site uses no cookies, advertising, or analytics tools. Game progress (saves) is stored only in the visitor's browser local storage (localStorage) and is never sent to a server. Clearing browser storage deletes the saves; JSON files the visitor exports stay on the visitor's own device. Fonts and images are served from the Site itself, so no requests are sent to third-party services.

3. Riot Games API data

The Riot Games API is not called from the visitor's browser. Separately, an offline collector uses the Riot Games API to download public ranked League of Legends match data from the Korean server and aggregates it into champion matchup and position-synergy statistics (including game counts). Only these aggregates are shown on the Site. They describe champions and roles, not individual players or visitors. Pro player ratings are computed from public official LCK match records (match data provided via Leaguepedia); no player photos are used. If a player asks us to stop using their name, we will anonymize it promptly.

4. Hosting

The Site is hosted on GitHub Pages. GitHub may process ordinary technical logs such as IP addresses under GitHub's own privacy policy. The operator does not sell visitor data and does not use the Site for betting or advertising.

5. Changes

If this policy changes, this page will be updated.
